# A first 12 weeks of strength and running

Prepared by Rowan, Hybrid Coaching Lead, as an example for Mark to review. This is a separate beginner scenario, not a replacement for Mark's competition programme.

## Starting point and aim

Assume an adult new to both running and strength training, comfortably able to walk for 30 minutes, with basic gym access. The aim is to establish two weekly strength sessions and three manageable run/walk sessions, then work towards comfortable continuous running. Thirty minutes is a possible endpoint, not a guaranteed result or necessarily 5 km.

If comfortable walking is not yet established, build that first. Repeat stages whenever needed; the calendar does not oblige the athlete to progress. New or worsening pain is a reason to stop and reassess, rather than push through the next stage.

## A typical week

| Day | Workout |
| --- | --- |
| Monday | Full-body strength A, about 35–45 minutes |
| Tuesday | Easy run/walk |
| Wednesday | Rest or comfortable walking |
| Thursday | Full-body strength B, about 35–45 minutes |
| Friday | Easy run/walk |
| Saturday | Rest or comfortable walking |
| Sunday | Easy run/walk |

Keep early lower-body strength volume modest so it does not overwhelm the next day's run. If soreness changes running mechanics, defer the run or use walking and reduce the next lower-body strength dose. The days can move, while retaining a non-running day between runs and separating the two strength sessions.

## Running progression

Walk for five minutes before and after each session. The walking breaks in the table occur **between** running blocks. All running is easy enough for conversational breathing. No threshold intervals, sprints or pace tests are needed during this introduction.

| Week | Running portion of each of the three sessions |
| --- | --- |
| 1 | 8 × 1 minute running; 90 seconds walking between blocks |
| 2 | 6 × 90 seconds running; 2 minutes walking between blocks |
| 3 | 5 × 2 minutes running; 2 minutes walking between blocks |
| 4 | Repeat week 3 and consolidate |
| 5 | 4 × 3 minutes running; 2 minutes walking between blocks |
| 6 | 5 × 3 minutes running; 90 seconds walking between blocks |
| 7 | 3 × 6 minutes running; 2 minutes walking between blocks |
| 8 | Repeat week 7 and consolidate |
| 9 | 2 × 10 minutes running; 3 minutes walking between blocks |
| 10 | 2 × 12 minutes running; 2 minutes walking between blocks |
| 11 | Three runs of 20, 22 and 25 continuous minutes, if ready |
| 12 | Three runs of 25, 25 and up to 30 continuous minutes, if ready |

Progress when the current sessions are manageable, recovery is satisfactory and running remains comfortable. Otherwise repeat the stage, shorten the running blocks or retain walk breaks. A completed walk/run programme is useful progress even when continuous running takes longer than 12 weeks.

For a new runner, time is the initial training dose; do not force an arbitrary distance or numerical pace. On a treadmill, choose a comfortable walking speed and an easy jogging speed, then adjust as needed. An app can remember those speeds and show both km/h and equivalent pace. The tracker should support timed stages as well as distance stages.

## Strength sessions

Use controlled technique and warm-up sets before demanding working sets. Choose loads that leave the stated number of repetitions available; no maximum test is needed.

| Position | Strength A | Strength B | Repetitions per working set |
| --- | --- | --- | --- |
| 1 | Goblet squat | Leg press | 6–10 |
| 2 | Dumbbell Romanian deadlift | Glute bridge | 6–10 |
| 3 | Dumbbell bench press | Incline push-up or chest press | 6–10 |
| 4 | Chest-supported row | Lat pulldown | 6–10 |
| 5 | Dead bug | Calf raise | 6–10 per side / 10–15 |

| Weeks | Working sets and effort |
| --- | --- |
| 1–2 | 1–2 sets per exercise; learn technique; leave 3–4 repetitions available |
| 3 | 2 sets per exercise; leave about 3 repetitions available |
| 4 | Consolidate: 1 set per exercise; no load increase |
| 5–7 | 2 sets; optionally 3 on the first exercise when recovery supports it; leave 2–3 repetitions available |
| 8 | Consolidate: 1–2 sets; no load increase |
| 9–11 | 2–3 sets on the first four exercises as recovery permits; 2 on the final exercise; leave 2–3 repetitions available |
| 12 | 2 sets; consolidate and review the next block |

Add repetitions before increasing weight. When every set reaches the upper repetition target with sound technique and the intended reserve, use the smallest available load increase and return towards the lower repetition target. Keep strength loads steady when running progression is already challenging. Rest approximately two minutes between demanding sets, longer when needed.

Keep these movements stable while learning them. Substitute for equipment, comfort or a clear coaching purpose, not simply to add novelty. Optional work, if introduced later, belongs at the end and must not be required for completion.

## Review at the end

Compare repeatable loads and repetitions, confidence with technique, comfortable running duration, attendance and recovery. Use those results to choose the next focus. A race, heavy single or other maximal test is not required.

## Evidence and scope

This exact combined schedule is a coaching synthesis, not an independently tested published protocol. It adapts gradual beginner running principles to a modest strength workload.

- [NHS Couch to 5K running plan](https://www.nhs.uk/better-health/get-active/get-running-with-couch-to-5k/couch-to-5k-running-plan/): three weekly run/walk sessions with a rest day between runs, gradual duration progression and walking warm-ups/cool-downs. The example above is a separate 12-week progression, not the NHS's nine-week schedule.
- [ACSM 2026 resistance-training guidance](https://acsm.org/resistance-training-guidelines-update-2026/): regular training of major muscle groups at least twice weekly and a practical emphasis on consistency.

Sources checked 27 October 2026. Exercise selection, exact sets, consolidation weeks and integration decisions above are proposed coaching choices that should adapt to the individual.
