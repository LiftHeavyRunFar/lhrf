# Stage 5 — weekly scheduling recovery

**The O1/O3 scheduling regressions are corrected. Taylor's improvement and every Stage 2 prescription/day are retained. The engine is ready for controlled, coach-supervised validation with verified inputs and explicit approval; the frozen profiles are not automatically cleared for training.**

Base: `0a1d1d3` on `investigate/taylor-visit-allocation`. This stage changes two coaching source files and adds evidence/tests. All previous evidence, benchmark facts, acceptance criteria, saved programme files and logs remain unchanged. The separate UI branch is not included.

## Root cause

Stage 1 appropriately weighted strength visits by available minutes and stopped treating a short health run as a race-specific long run. But it also removed the former weekday preference for strength-first health programmes. Candidate calendars were compared mainly by within-visit balance and minute-window weights, with an early-week tie-break. A local same-lift adjacency preference did not account for squat/deadlift interaction across the complete week. Equally feasible calendars therefore selected M/T/W, including near-max deadlift immediately before near-max squat.

## Small, general correction

- `coach-engine.js` assigns **`weeklyStressVersion: 1` only at the explicit new-proposal boundary**. Existing saved version-one visit allocation is retained when this new marker is absent. The canonical final-heavy calendar supplies actual final-exposure dates; the canonical recovery classifier supplies affected lifts. Recovery evidence is not reinterpreted by a separate scheduling readiness model.
- `coach-constraints.js` adds a relative weekly cost to the existing complete-calendar search. Heavy/volume, speed/light/maintenance and easy/quality/long running have different demand weights. Longer observed long-run duration increases interference cost. The cost considers lower-body interaction, same-lift spacing, upper-body concentration, same-day mixing and lifting/running interference.
- A continuous inverse-distance penalty includes **both directions around the seven-day cycle**, including Sunday-to-Monday. Canonical final-heavy dates add a soft proximity cost, without inventing new taper windows. These are planning heuristics, not physiological recovery scores or universal minimum rest intervals. Consecutive sessions remain permitted when availability, dose or an explicit split warrants them.
- Existing availability, frequency, protected long-run placement, mixed/separate permissions, visit-window weights, final fitting, event feasibility and dated recovery rules remain in force. Explicit athlete splits bypass reshuffling. No athlete names or benchmark IDs occur in the production correction.
- A stability cost counts components moved from the previous allocator's proposal. A candidate must offer more than a marginal cost improvement before replacing a coherent layout. This avoids needless changes such as moving Idris's easy run while retaining meaningful improvements for O1/O3. The reference is a newly generated candidate, not a read or rewrite of the athlete's approved calendar.

The score deliberately represents the recurring heavy/volume/speed pattern rather than redesigning the calendar each deload week. Absolute future load suggestions still come from the existing prescription policy, and actual recovery remains a review condition. This is an incremental scheduling improvement, not a globally optimal search over every possible exercise grouping or individual recovery prediction.

## Remaining weaknesses and readiness

No new high-severity scheduling or prescription regression was found in these nine complete replays. The allocator still uses relative role-based demand estimates, a greedy within-visit grouping and soft weights. It cannot infer individual recovery or guarantee an optimal calendar for arbitrary inputs; fixed athlete splits can intentionally retain difficult distributions. Validate completed-session effort, sleep, pain, duration estimates and next-day response in a limited pilot.

The previous endurance conditions remain: O1's four-hour peak long run needs a current tolerance/fueling/recovery review; O1/O2 require verified mileage/long-run history and actual post-marathon recovery; O2's easy-only running taper may reasonably be reviewed for small familiar pace reminders after recovery is established. Idris's later half-marathon preparation remains conditional on actual completed training. Sofia needs sufficient performance/duration evidence. Keiko needs recovery reassessment and a genuinely feasible event window/date. The original-three dates, visit caps and experience assumptions still need real athlete confirmation.
