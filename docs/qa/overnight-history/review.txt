Root cause and change
The former lookup demanded numeric programme week minus one plus a matching
session day/name/ID. Stage 8 preserves records, but programme replacement changes
those coordinates. Week one returned no history at all.

A read-only module now selects the latest suitable earlier performance separately
for each exercise by actual London calendar date, exercise identity, variation,
load/dose convention and exact recorded setup. It has no programme-week condition.
Known different variations/venues cannot match. Original records and RPE are used
without corrections, rounding or feedback into coaching. Top/back-off roles are
shown when recorded; their actual sets remain together as session context.

Basic legacy Squat/Bench/Bench press/Deadlift rows may be shown without a variant
ID, explicitly warning that venue/setup was not recorded. Missing setup on other
variations or machine/accessory exercises prevents comparison. Failed, technically
failed, optional, warm-up, incomplete, invalid, untrusted-RPE, zero external-load,
undated, current-day and future rows are excluded. Missing RPE is labelled rather
than invented. This does not remove or edit any historical records.

Limits and release route
Calendar-date matching intentionally excludes same-day work, including an active
session's own records. Stale records show their real date; no freshness-based load
recommendation is made. Unknown legacy machine setups remain unavailable. A
reference is contextual evidence, never an automatic load prescription. Physical
phone/accessibility acceptance remains a useful final check; automation does not
constitute a human coaching sign-off.
