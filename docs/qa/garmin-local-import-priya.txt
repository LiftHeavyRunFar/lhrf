Scope/limitations accepted
-------------------------
The FIT decoder deliberately supports a strict bounded subset. Unsupported compressed
timestamps/developer fields/multisession are safe rejections, not promised support;
export a single running TCX instead. This trade-off avoids a full SDK/profile payload.
TCX elapsed is a trackpoint span and moving is unavailable. A span shorter than the
authoritative timer is deliberately rejected rather than guessed. GPX distance is an
estimate and its pace uses elapsed time, including pauses. Raw files are not archived.
Exact-byte identity cannot prove cross-format identity: near matches require manual
acknowledgement, preserving existing data. No migration, refresh or post-save outcome/
link editor is included. Explicit completed is athlete confirmation, not compliance
analysis. No physical Garmin/Forerunner165 end-to-end claim is made.

The parent implementation agent separately records whole-suite and other browser
regressions, final source-scope verification and final commit SHA. This report's
counts above are the independent checks actually executed by Priya.
