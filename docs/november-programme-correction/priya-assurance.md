## Three-athlete challenge and regression evidence

I independently extracted the exact draft sources into scratch directories and ran their existing tests without changing the source or expected assertions. These are fictional software counterexamples, not three physiological replications of the owner.

- **A, strength-priority hybrid:** low-volume squat/deadlift maintenance can coexist with useful advanced bench practice. Speed sets are not equivalent to hard bench sets. A's abrupt support reductions and very low late running dose deserve review; adding a compulsory heavy lower single or mileage would not follow from this case.
- **B, running-priority novice lifter:** conservative suggested loads can conflict with completed effort-compatible straight sets, while novice evidence does not enter the top-set progression path. Reconcile load with execution and effort; do not add advanced singles or transplant the owner's speed-bench prescription. The large race-week reduction is a review concern, not proof of an optimal universal cut.
- **C, development hybrid:** useful recurring main work matters, but repeated numeric suggestions can still permit RPE-led progression. Concentrated main/accessory work and staggered deloads can either manage or waste tolerance. Do not generalize A's maintenance dose to C's development objectives or increase C despite repeated fatigue.

Paired structured evidence changes running but does not resolve every novice lifting path. Green characterization tests reproduce these defects; they do not implement the recovery proposal.
