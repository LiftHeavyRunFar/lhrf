## Remaining coaching decisions

Normal review should consider recurring comparable performance, adherence and recovery over roughly 2–4 weeks; this is a practical review horizon, not an automatic trigger or universal progression window. Session feedback primarily changes execution/monitoring, weekly reflection helps interpretation, and meaningful programme changes require a reason and athlete approval. Injury or significant safety concerns can require immediate action. No automatic programme regeneration is introduced.

Remaining conventions include effort conversions, rounding, evidence horizons, planned reduced weeks, quality budgets, progression fractions, provisional return fractions and event-priority taper choices. A/C still carry substantial support work; improving novice load calibration can increase fatigue. These are visible review questions. The evidence supports this targeted correction more strongly than it supports autonomous optimisation or a specific owner's next load.
