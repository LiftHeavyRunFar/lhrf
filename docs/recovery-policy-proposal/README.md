# Recovery and stable-review policy proposal

**Decision status: proposed policy version 1, awaiting Ella and Rowan review. No recovery policy, prescription, app flow or saved programme is changed.** This branch contains a proposed decision contract, fictional inputs, current-engine characterizations and independent assurance. It does not implement a recovery state machine or generate a replacement owner programme.

Evidence baseline is PR #128, commit `cc8eef90b628269758bfdcb9b383aee8c41e2895`. Rowan owns this proposal; Priya challenges it independently. The [evidence standard](../independent-coaching-audit/evidence-review.md), [IA-03/04 register](../independent-coaching-audit/defect-register.md) and [constitution](../independent-coaching-audit/coaching-constitution.md) remain the scientific/governance foundation. The approximately 2–4-week normal-review horizon is a practical default, not a validated adaptation threshold.

## Decisions requested

Approve or revise the following semantic contract before authorising implementation: interpret dated recovery evidence once; preserve the scope of that interpretation through every generation pass; distinguish tolerance of easy running from quality running, lower lifting and unaffected upper-body work; never infer clearance solely from elapsed days; and give each restriction a review point and a way to restore justified training. A generic normal report must not authorise full heavy loading or prior habitual volume.

The smallest eventual implementation should reuse current generation and approval pathways with one shared interpretation and provenance. It should not add a new scheduler, exercise library or autonomous training service. No numerical recovery dose, minimum recovery duration, mandatory biomarker, new RPE threshold or automated readiness score is approved here. Existing 14/21-day windows are planning conventions under review, not physiological truth.

## One recovery interpretation, with explicit scope

For a future opt-in `recoveryPolicyVersion: 1`, a reviewed recovery decision should reference the programme/version and relevant event or concern; dated source observation IDs; the affected activities; what remains unknown; the smallest agreed action; who reviewed it; athlete approval where material; and the next review point. These are proposed contract fields, not a new stored schema or a marker introduced into current configuration on this branch.

The scope questions are ordinary coaching questions, not five independent numerical readiness scores:

1. Are systemic symptoms or significant safety concerns present?
2. Is ordinary easy running comfortable, including the subsequent response?
3. Has faster running or a longer dose actually been tolerated?
4. Has the specific lower-lifting task been tolerated at an appropriate initial dose?
5. Is upper-body work genuinely unaffected, including setup, leg drive and whole-session demand?

Evidence for one task does not answer another automatically. Comfortable daily movement can support trying a small familiar activity; it does not prove full loading is safe. Easy-running tolerance can support easy running without clearing intervals. A comfortable warm-up is weaker evidence than a comparable completed session with no subsequent worsening. Returning some intensity and restoring full previous volume require separate rationale; do not increase both simply because an event timer ends.

The event is a reason for an initial conservative plan and a timely check-in. Once current activity-specific evidence is reviewed, later passes must consume that same interpretation rather than overwriting it with a second unconditional post-marathon rule. Preserve distinct restrictions when evidence justifies them. This reconciles IA-03 without simply deleting all initial caution.

For IA-04, context-only and paired evidence should resolve to the same **meaning**, or the system should identify ambiguity and request clarification. Do not silently assume a lower-lifting concern means all running is intolerable; do not silently assume that it excludes running when the athlete specifically reports uncomfortable easy running. The same applies to B's novice work. Experience affects prescription, not whether a credible unresolved concern is noticed.

## Proposed recovery decision matrix

All proposed actions below are conditional review outcomes. They do not assign a safe kilogram/RPE/mileage from a fictional status or authorise activation. Normal changes preview the exact affected future sessions for athlete approval. The athlete can stop provoking work immediately.

| Trajectory and dated evidence | Running decision to discuss | Lower-lifting decision to discuss | Upper-body decision and review |
| --- | --- | --- | --- |
| **Fast:** 5 November short easy run comfortable, no next-day worsening on 6 November; normal daily activity; familiar lower warm-ups comfortable; full loading untested. | A small easy dose based on actual recent tolerated activity is defensible for review. Do not jump to all habitual kilometres plus quality because `normal` cleared an event field. Confirm subsequent tolerance before adding duration or faster work. | Discuss a bounded familiar return, replacing rather than adding to existing lower work. Establish task/load tolerance first; no immediate full-heavy/full-volume restoration. Keep next exposure conditional. | Retain the familiar approved purpose/dose if current systemic, setup and execution evidence supports it; remove only restrictions shown no longer relevant. Review during execution and after the next relevant exposure. |
| **Slow:** comfortable easy running not restored; familiar lower warm-ups unusually effortful on 6 November. | Hold quality and long-run progression. Shorten/stop an intolerable easy attempt; choose an acceptable nonprovoking alternative or rest with the athlete. Do not describe the projected .4/.6/.65 volume factors as required activity. | Retain or further reduce affected work according to the actual task response. No heavy return merely because 14/21 days pass. Reassess cause, adherence and normal function. | Ask whether upper work/systemic fatigue are affected; absence of a report is unknown. Preserve genuinely unaffected work if tolerable. Agree the next practical check-in, sooner for worsening. |
| **Uncertain:** event completion is known; no post-event report. | Ask targeted questions before a material return-to-quality increase. Previously agreed easy activity may remain available if tolerated; no compulsory run or permanent ban based only on the historical event. | Clarify current function and any actual warm-up/session evidence; retain a provisional bounded option or defer provoking activity, rather than guessing readiness or forbidding all lifting indefinitely. | Keep the prior approved plan as the baseline. A review-due notice has a reason, contact path and next planned visit/date; it is not an automatic activation block for unrelated work. |
| **Worsening:** focal pain starts on 5 November and affects walking on 6 November. | Stop provoking running and obtain appropriate assessment promptly. Do not wait for the weekly review or a 2–4-week trend. No diagnosis or exact return date is invented. | Do not load a provoking movement until assessed/reviewed; avoid using a low RPE label as assurance that it is safe. | Unaffected work is conditional on systemic status and nonprovoking setup/support. Significant safety concern overrides programme stability; document the temporary scope and follow-up. |
| **Partial:** easy running comfortable but squat warm-up uncomfortable on 6 November. | Easy tolerance may justify keeping an agreed easy dose. Quality/longer running still need evidence; lifting pain should be considered without automatically clearing or banning all running. | Hold/modify the provoking lifting task and review it specifically. Do not interpret a general normal-running response as lower-lift clearance. | Familiar nonprovoking upper work can remain conditional. Resolve task-specific conflict explicitly rather than letting whichever old field is read first win. |

**Reassessment is an action, not automatic clearance.** At the agreed review point, add new dated evidence, retain unresolved concerns, and agree the next decision. An old unresolved concern remains relevant to the review; it is not proof that symptoms persist in every later week. An overdue report becomes “review due / information missing”, not “fully recovered” and not an indefinite universal restriction. If the athlete declines a material proposal, preserve the approved programme and explain the uncertainty; do not press the same proposal every session. Symptom-based execution stop rules remain available.

## A/B/C consequences and false decisions

**A, strength-priority experienced lifter:** useful bench practice can be lost by a blanket clipping pass even when upper work is unaffected. The opposite mistake is restoring heavy bench from a generic normal answer while systemic recovery, leg drive or the remaining taper make it inappropriate. Keep familiar purpose and avoid catch-up work. Its modest running base increases the need to distinguish actual post-event tolerance from habitual pre-event kilometres; the marathon is only a stress-test event here.

**B, experienced runner and novice lifter:** a large habitual running base does not prove post-marathon current capacity. Easy running can be restored separately from quality. Familiar novice straight sets need a recovery review just as advanced top sets do; do not add heavy singles to fit existing review machinery. The current paired input protects running quality but does not retain the later novice lifting restriction. The proposed contract must cover this branch without treating all novice training as dangerous or permanently light.

**C, intermediate general hybrid:** prioritize a repeatable dose and observation over a new peak or continuous cuts. Slow lower fatigue should not disappear for running on day 21 while limiting lifting forever. In partial recovery, retain justified easy/upper activity and review affected tasks. No imminent event means there is little reason to compress a return merely to catch up with the template.

False clearance can expose an unrecovered athlete to an inappropriate task; false persistent restriction can discard useful training, reduce confidence and make the app's future output unhelpful. A more complex score cannot remove this uncertainty. The proposal therefore requires explanation and an individual review path, with minimal activity-specific changes and a follow-up.

## Stable adaptation in practice

| Signal or interval | Practical response | Guard against |
| --- | --- | --- |
| One unexpectedly hard or easy session | Record comparable execution, conditions and symptoms; use already-agreed effort/technique adjustment and monitor. | Rewriting structure, escalating load from a good day, or diagnosing persistent fatigue from one score. |
| Weekly reflection | Compare planned/completed dose, quality, adherence, objective performance and recovery. Ask what changed and what is missing. | Equating missed training with physiological inability; treating missing data as a bad score. |
| Repeated pattern across roughly 2–4 weeks | Review the combined case and propose the smallest targeted change if warranted. Actual dated comparable opportunities matter more than row counts or epoch-week bins. | A fixed waiting period, automatic progression entitlement or repeated cut before the last change is evaluated. |
| Poor sleep/subjective fatigue but stable performance and comfortable recovery | Interpret context and athlete preference, monitor, and discuss a modest adjustment if needed. | Dismissing reports because performance is stable, or automatically cutting an accustomed programme solely on an isolated complaint. |
| Persistent comparable performance decline with adequate adherence, even without low subjective scores | Investigate recovery, task validity, conditions and goals; review promptly when coherent evidence warrants. | Requiring a negative survey before responding; a rigid 4-week delay. |
| Dense but misleading positive logs, duplicate rows or old/future data | Exclude unsuitable capacity evidence and preserve it in historical context; monitoring/discussion remains possible. | Calling 48 hours of clustered rows a sustained trend. Genuine high-frequency plans can have three due visits in 48 hours; mapping them alone does not establish a repeated pattern across the plan cycle. |
| Injury/significant pain/systemic illness | Stop or modify provoking work and seek appropriate assessment immediately. | Making safety dependent on enough completed sessions, a review timer or athlete approval to stop. |

Objective performance, adherence and recovery govern a normal material-change rationale alongside athlete experience; an isolated subjective score is not sufficient. This does not mean objective data can veto pain or the athlete's right to reduce/stop. Normal review should compare recurring planned opportunities across elapsed time and explain uncertainties. A “2–4 week” phrase is not a numerical rule to code blindly.

Every material proposal must name the specific future change, reason and source interval; distinguish alternatives and expected tradeoffs; record athlete approval for that version; and state what response will be reviewed. Rejected/deferred proposals leave the baseline unchanged. After a reduction, assess whether the issue improved before adding another reduction. Stable, accustomed high-frequency work without actual impairment is not itself evidence that the athlete needs less training.

## Preservation, versioning and rollback contract

When separately authorised and implemented, the policy must be opt-in for new/reviewed proposals. Old unversioned and approved policies retain their exact prescriptions. Frozen `reviewedProgramme` snapshots remain frozen; new observations create review information, never silent regeneration. A source report edit, app refresh, elapsed date, new engine build or approving a different programme cannot opt an old snapshot into the new policy.

Any future approved targeted replacement records source programme/snapshot digest, policy version, exact affected future session IDs, rationale/evidence and approval. Archive the prior approved future schedule and original native prescription. Check that the active source still matches immediately before applying; a stale proposal is rejected for re-review. Rollback restores the prior future snapshot through the same explicit approval route; it never rewrites already completed sessions, original RPE, activity/Garmin links or source history. No acceptance of the proposal authorises an unrelated later change.

Readiness updates must not erase tested performance evidence, relabel completed work, change a historical policy marker or clear a concern by mutating the original report. Append the review decision/provenance instead. If a recovery return is constrained by `runningReturnObservation`, review its low-week origin and current tolerated activity separately: neither treat the low recovery week as normal capacity nor preserve an indefinite compounding cap without reassessment.

| R6, partial and conflicting reports | Easy-running tolerance, quality readiness, lower-lifting tolerance and upper setup are not conflated. Newer worsening evidence is not overridden by an older cleared/resolved record; mutually conflicting current evidence prompts clarification. |

Implement these with contrasting useful-dose positive controls as well as restrictions. An engine that blocks all activity would fail R1/R3/R4 despite avoiding some false clearances. Testing documents software behavior, not proof of no physiological risk.
